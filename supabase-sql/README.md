# CodCraft Supabase SQL

Open Supabase Dashboard, select **SQL Editor**, and run these files in numerical order:

1. `01-login-signup.sql`
2. `02-profile-security.sql`
3. `03-existing-users.sql`
4. `04-progress-scoring.sql`
5. `05-progress-security.sql`
6. `06-leaderboard.sql`
7. `07-leaderboard-index.sql`

Use `00-complete-setup.sql` instead when you want the original all-in-one CodCraft schema.

The scripts are rerunnable. Login passwords remain inside Supabase Auth and are never stored in the public tables.
